Quantization and distillation research, open-sourced and published.

Car Aura Collector

A LangGraph agent that picks one car, hunts its shoot across the web, and keeps ten frames.

  • StateGraph with plan, harvest, rate and save nodes, plus a conditional edge back to harvest when portrait shots run short.
  • ddgs harvest with a 640px floor, watermark and AI-art blocklists, and perceptual-hash dedupe on every candidate.
  • Rating started on Gemma-4 on Ollama Cloud, scoring aura and flagging real photos versus renders, before the graph moved to a local rater.
  • Four unattended runs a day, one git commit per batch, and a Flask gallery that serves the archive.

Agent verification

LangChain Q&A agent

An answer agent with a separate fact-checker that can reject the draft.

  • Two agents in one loop: the answer agent drafts, the fact-checker returns a structured true or false verdict, and a false verdict sends the draft back with corrections.
  • The loop stops on approval or after three attempts, so a bad answer cannot spin forever.
  • Runs on Sodeom's OpenAI-compatible endpoint at sodeom.com/v1 with the beam model.

Agent research

blogs-langchain

A research agent that returns a cited, fact-checked answer instead of a confident guess.

  • Searches Sodeom, fetches the top pages, strips scripts and styles, and converts the HTML to clean Markdown.
  • The LangChain agent drafts from that dossier, and the fact-checker retries with corrections before the answer is written out.
  • Both the LLM and the search come from Sodeom, so there is one vendor in the loop.
